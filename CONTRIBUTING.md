# Contributing to Chroma Link IoT

Thanks for contributing! We welcome improvements, bug fixes, and documentation.

How to contribute

- Open an issue describing the bug or feature you'd like to add.
- If you'd like to contribute code, create a feature branch from `main` with a descriptive name: `feat/<short-desc>` or `fix/<short-desc>`.
- Keep changes focused and add tests or build instructions where appropriate.
- Follow the commit message convention: `type(scope): short summary` (e.g., `fix(firmware): correct PWM timing`).

Pull request checklist

- [ ] The code builds and runs locally
- [ ] Relevant documentation is updated (docs/ or README)
- [ ] Commit history is clean and meaningful
- [ ] CI (if any) passes

Coding style

- Keep code style consistent with existing files. If the project uses a linter or formatter, run it before opening a PR.

Contact

If you have questions, open an issue or tag the repository maintainer in a PR.
